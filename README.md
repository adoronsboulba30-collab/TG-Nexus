# TG Nexus — V1
Mini interface mobile de démonstration pour un futur Telegram Mini App.

## Mise en ligne
1. Crée un dépôt GitHub nommé `tg-nexus`.
2. Ajoute `index.html`, `style.css` et `app.js` à la racine.
3. Dans Settings → Pages, active GitHub Pages depuis la branche principale.
4. Utilise l'URL HTTPS fournie par GitHub Pages pour la future Mini App.

## À modifier
Dans `app.js`, remplace les URLs `https://t.me/` par les liens réels de tes canaux.

Cette V1 est une maquette front-end : elle n'a pas encore de base de données, authentification Telegram ou soumission réelle de canaux.
